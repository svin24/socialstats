# 2026-10-28 initial socialstats

## Goal

Ship a local CLI in `~/dev/socialstats` that collects the owner's own YouTube
Analytics and imported X CSV analytics into dated JSON/CSV files, packaged
with Nix and a Home Manager systemd user timer.

## Constraints respected

- Work only inside `~/dev/socialstats` plus `~/.local/bin/socialstats` symlink
- Did not edit `~/dev/nix` or `~/work`
- Did not create or push a GitHub repo
- Did not run the OAuth flow or use real credentials
- Did not install system packages; toolchain via Nix

## Implementation

- Language: Go (`golang.org/x/oauth2` only)
- Commands: `auth`, `fetch`, `import-x`, `status`
- Config/data: XDG dirs, never in git
- Tests: CSV parser, date range, store dedup, webhook redact, CLI help/dry-run
